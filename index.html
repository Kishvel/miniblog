Lo que he aprendido de HTML

HTML es el lenguaje de marcado que se utiliza para estructurar el contenido de las páginas web. He aprendido a usar etiquetas como <h1>, <p>, <article>, y muchas otras para organizar el contenido de manera semántica.

También he aprendido lo que es la jerarquía de etiquetas y cómo estructurar una página web de forma semántica y accesible.
